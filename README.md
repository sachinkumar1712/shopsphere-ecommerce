
# ShopSphere - E-Commerce Website

ShopSphere is a responsive frontend e-commerce website built using HTML, CSS, JavaScript and Bootstrap. It provides an interactive online shopping experience with product browsing, cart management, wishlist, product comparison and simulated checkout.

## Features

- Responsive navigation bar
- Modern homepage and hero section
- Dynamic product listing
- Product category filtering
- Real-time product search
- Price and rating-based sorting
- Product details modal
- Shopping cart management
- Wishlist management
- Dynamic price calculation
- LocalStorage data persistence
- Checkout form validation
- Demo payment options
- Order confirmation
- Order history dashboard
- Order cancellation
- Customer reviews and ratings
- Coupon codes and discounts
- Product comparison system
- Dark and light mode
- Back-to-top button
- Responsive design
- Accessibility improvements
- SEO metadata
- Lazy loading for product images

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html using Live Server or a web browser.
4. Explore the website and its features.

## Limitations

This project is a frontend demonstration.

It does not include a backend server, real authentication, a production database or real payment processing.

All orders and payments are simulated. Use fictional customer information when testing checkout.
